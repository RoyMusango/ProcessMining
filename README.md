# Petri

Application personnelle de révision pour la partie Process mining du cours Health and Social Mining (I-MANA-223, UMONS) : fiches avec plateaux de réseaux de Petri jouables, prédiction avant chaque coup, graphe d’accessibilité, révision espacée, exercices et tuteur IA.

Application web statique, sans build, sur le moteur de Learnable (AppLangues). Les clés API restent dans le navigateur. Formules rendues avec KaTeX (licence MIT, `js/vendor/katex`).
